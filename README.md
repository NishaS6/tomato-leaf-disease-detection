# 🍅 Tomato Leaf Disease Detection Using Deep Learning

## Overview

This project uses Deep Learning and Computer Vision techniques to identify diseases in tomato leaves from uploaded images. The system helps detect plant diseases early, enabling better crop management and reducing agricultural losses.

## Features

* Upload tomato leaf images
* Automatic disease classification
* Deep learning based prediction
* User friendly Streamlit interface
* Fast and accurate disease detection

## Technologies Used

* Python
* TensorFlow
* Keras
* OpenCV
* NumPy
* Streamlit

## Disease Classes

* Healthy
* Early Blight
* Late Blight
* Leaf Mold
* Septoria Leaf Spot
